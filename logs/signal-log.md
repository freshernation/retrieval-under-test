# Signal log

**Five numbers a day**, and every `SIGNAL` block an AI role prints at the end of a session.

## The five numbers

| Date | Minutes on the labs | Minutes reading | Predictions I got wrong | Tests red at the end of the day | Confidence 1-5 |
|---|---|---|---|---|---|
| | | | | | |

"Predictions I got wrong" is the interesting column. A week with a zero in it means you are
predicting things you already know, and the *Predict first* blocks have stopped doing
anything.
